# Tatort im Kiez – Akte Weihnachten

XR-Prototyp (Hochschulprojekt) zur Kampagne „AKTE WEIHNACHTEN – Ihr seid die Jury.“ für die immersive Gerichtsshow THE JURY im Colosseum Berlin.

**Studentisches Projekt – keine offizielle Seite von Colosseum Berlin oder Fever.** Fall 24/12 ist ein Kampagnen-Probefall; im Colosseum wird ein anderer Fall verhandelt.

- 360°-Tatort im Browser (A-Frame 1.6.0), 5 Beweisstücke, Urteil und Jury-Ausweis
- AR-Beweisstück „Der Schlitten“: iPhone/iPad per AR Quick Look (`ar/beweis_schlitten.usdz`), Android per Scene Viewer/WebXR (`ar/beweis_schlitten.glb`)
- Barrierearme 2D-Akte als gleichwertige Alternative
- Datenschutz: keine Drittanbieter-Requests – A-Frame und Schriften liegen lokal in `vendor/` (Lizenzen in `vendor/licenses/`); Analytics nur lokal im dataLayer (Prototyp)

Prototyp · KI-gestützt erstellt · keine echte Ticketbuchung.
